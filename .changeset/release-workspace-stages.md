The release workspace is split into four stages — Draft, Review, Deliver and Launch — each on its own screen, opening on the release's current stage. Actions that are not available yet stay visible but disabled, with the reason on hover and focus. The dashboard follows the artist design with the current release, attention items, recent releases, coming dates, activity and listening data. Release tasks are no longer part of the artist workspace: the Tasks page, the task panel and task results in search and notifications are gone. The delivery plan can now also be changed after Bitrate approves a release. Guests on public pages such as password recovery are no longer sent to the login page when the API reports them as signed out.
