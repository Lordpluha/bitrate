# Design specifications

Specifications capture an agreed design before an implementation plan is written. Use them
for cross-cutting behaviour, data-flow changes, or work where the boundary itself needs
review.

Specs describe the problem, invariants, ownership, alternatives, risks, and acceptance
criteria. Once approved, `/sp-planner` may derive an implementation plan under
[`../plans/`](../plans/).
