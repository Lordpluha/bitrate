# Чек-лист №3 — Продуктовый паритет со Spotify

> Проверяет не количество файлов, а то, что пользователь реально может сделать в приложении.
> Актуализировано: 2026-08-11 по текущим маршрутам, API-модулям и frontend-чек-листу.
> Аудио-движок оценивается отдельно и здесь не считается блокером интерфейсной части.
>
> Статус: ✅ готово · 🟨 частично/нужна ручная проверка · ❌ отсутствует

## Что осталось на фронте без нового backend API

1. Завершить ручной accessibility-прогон: screen reader, 200–400% zoom, только клавиатура.
2. Довести менее важные responsive-состояния и screenshot-регрессии для вложенных `/main` страниц.
3. Сделать UI управления/перестановки очереди, если это требуется продуктом.
4. Добавить frontend flow удаления аккаунта и экспорта данных только после согласования поведения.
5. Дочистить тексты, переводы и редкие empty/error states после ручного QA.

## Что требует backend или отдельного направления

1. Batch reorder endpoint для drag & drop треков плейлиста.
2. Реальное применение streaming quality и normalization в аудио-движке.
3. Воспроизведение подкастов и отдельная стратегия media source.
4. Upload flow для обложки плейлиста, если отдельного endpoint действительно нет в финальном контракте.
5. Платежи, entitlement enforcement, реклама и ограничения Free.
6. Friend Activity, Jam/Blend, radio и realtime совместное прослушивание.
7. Офлайн-хранилище аудио и политика лицензирования/квот.

## Что изменил обновлённый seed

Seed теперь создаёт данные для проверки актуального продукта, а не только случайных карточек:

- воспроизводимые тестовые пользователи с корректно хешированным паролем и подтверждённой почтой;
- жанры и связи жанров с треками, артистами и альбомами;
- TrackArtist credits и нумерованные AlbumTrack/PlaylistTrack;
- настройки, подписки, лайки, follows, историю, поисковые запросы и уведомления;
- подкасты, эпизоды и сохранённые выпуски;
- публичные/приватные плейлисты с датой добавления и стабильным порядком треков.

Это позволяет проверять Home, Search, Library, profiles, settings, podcasts и playlist detail на одной локальной базе без ручного наполнения Prisma Studio.
