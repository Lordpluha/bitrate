# Bitrate for Artists — Pencil designs

One artist-workspace design in three themes. The screens, layout and copy are the same in
every theme; only colours, gradients and shadows differ. The app implements them as one
layout with Light / Dark / Dim palettes.

| Path | Contents |
| --- | --- |
| [`web-artist.md`](web-artist.md) | Shared screen inventory and design checklist |
| [`assets/`](assets/) | Images shared by all three themes |
| [`dim/`](dim/) | Dim (default) theme: `web-artist-dim.pen` and its `DESIGN.md` |
| [`dark/`](dark/) | Dark theme: `web-artist-dark.pen`, `DESIGN.md` and the theme pass notes |
| [`light/`](light/) | Light theme: `web-artist-light.pen`, `DESIGN.md` and the theme pass notes |

Each `.pen` references `../assets/` and the web-player design assets in
`../../web-player-disign/`. Open `.pen` files only through Pencil.
